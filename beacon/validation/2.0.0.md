Date: 2026-10-30.

## Public Package Acceptance

A new application with an empty npm cache and no user npm configuration installed all three exact `2.0.0` versions from the public npm registry. Its lockfile contains public registry URLs and SHA-512 integrity values, without local archives or repository workspaces. On Node.js 24.22.1, the installed product exports `HttpProfilingExporter`, `NodeProfiling`, and `startProfilingFromEnv`; the CommonJS register entry produced traces and compatible multipart pprof profiles from the unchanged zero-code application to local receivers.

## Limits and Rollback

Security remains opt-in, uses event schema v2 and fingerprint v1, and requires Node.js 22.22.3+ or 24.11.1+ when enabled. Its remote events are compact per-request findings and periodic runtime dependency inventories. The Security event wire format differs from 1.3.1, so upgrade all three Beacon packages together and update consumers of schema v1. The complete inherited upstream and external backend compatibility matrices were not run; this acceptance covers the Beacon CI matrix and local OTLP trace, Log, and pprof receivers.

Rollback: pin all three Beacon packages to `1.3.1` in a clean application. Published package versions and source tags are immutable.
