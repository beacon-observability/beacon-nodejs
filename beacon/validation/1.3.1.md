## Public Package Acceptance

A clean application with an initially empty npm cache and no user npm configuration installed all three exact `1.3.1` versions exclusively from the public npm registry. The lockfile contains public registry URLs and the accepted integrity for all three packages, without local archives or repository workspaces.

On Node.js 24.16.0:

- The installed product exports exactly `HttpProfilingExporter`, `NodeProfiling`, and `startProfilingFromEnv`.
- All six installed-package regression cases passed: disabled/native failure isolation, idle native-profiler process exit, ESM instrumentation with an existing loader and Security disabled, consistent trace/profile resource identity with `profiler_version:1.3.1`, application-owned SIGINT draining, and active Security OTLP Log export before SIGTERM shutdown.
- The public CommonJS register entry ran the unchanged zero-code application and exported traces and compatible multipart pprof profiles to local receivers.
- All 13 installed-package SBOM tests passed, covering unchanged snapshot suppression, health heartbeat volume, loaded-component retention after URL-cache eviction, hoisted workspace dependencies and package identity.

## Limits and Rollback

Security remains opt-in, uses schema and fingerprint version 1, and requires Node.js 22.22.3+ or 24.11.1+ with its documented synchronous-loader capabilities. Use the ESM `--import @beacon-observability/nodejs/register` preload for Security; CommonJS `--require` initializes tracing and profiling only.

Corrected workspace inventories can contain more components and consume more memory. Coordinated cleanup has a 2.5-second best-effort bound; forced termination and exhausted deadlines can lose records, and unfinished wall samples are discarded. Optional native profiling still depends on supported runtime/platform binaries.

This acceptance covers local trace, Log and compatible pprof receivers. The complete upstream and external backend compatibility matrices have not been run, and this release does not add OpenTelemetry Profiles signal support.

Rollback: pin all three Beacon packages to `1.3.0` in a clean application. Published package versions and source tags are immutable.
