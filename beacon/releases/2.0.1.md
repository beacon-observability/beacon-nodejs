# Beacon Node.js 2.0.1

Security findings classified as `attack_evidence.status=no_evidence` are no longer
exported by default. Set `BEACON_SECURITY_EXPORT_NO_EVIDENCE_ENABLED=true` to restore
the previous behavior. `unknown` and `suspected` remain eligible, and SBOM inventory
export is unchanged. Filtering precedes queue admission and does not count as loss.
Internal detection, local finding snapshots, span summaries, and same-request
evidence upgrades remain available.

This is a GitHub source and candidate-artifact release. npm publication is pending
restoration of publishing credentials; the public npm release remains 2.0.0.
Do not use an npm installation command for 2.0.1 until all three matching packages
have been published.

The source uses schema v2 and fingerprint v1, with the same pinned OTel baseline
as 2.0.0. Security runtime support remains Node.js 22.22.3+ or 24.11.1+.

Rollback: pin all three Beacon npm packages to 2.0.0. To keep the new build and
restore ordinary finding exports, enable the configuration switch above.
