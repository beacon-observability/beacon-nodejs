# Beacon Node.js 2.0.2

This maintenance release records the released Contrib baseline
`fc3b13eb41e9512fb0d769b431583f90b5ef8326` and its complete source history.
Only the three Beacon-owned packages are published by Beacon; inherited
OpenTelemetry packages retain their own publication lifecycle.

The product continues to consume auto-instrumentation 0.80.x and Core 2.x.
The newer inherited source workspace is not substituted for those customer
runtime dependencies. The declared Node.js 18.19+/20.6+, 22 and 24 support
range is retained. Opt-in Security still requires Node.js 22.22.3+ or 24.11.1+.
Security uses schema v2 and fingerprint v1 and filters no-evidence findings by
default, as in 2.0.1.

All three Beacon packages use version 2.0.2. Candidate tarball installation,
zero-code injection and runtime-matrix results must be checked before
publication. Publication receipts and exact package digests accompany the
GitHub Release.

Rollback: pin all three Beacon packages to the previous accepted release 2.0.1.
