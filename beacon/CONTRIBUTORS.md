# Beacon Node.js Contributors

Beacon Node.js preserves the complete OpenTelemetry JavaScript Contrib history,
so the GitHub contributors graph includes inherited upstream authors. This file
lists contributors whose Beacon-specific work and account identity have been
verified. It does not replace Git history, license attribution, or repository
permissions.

## Maintenance Rules

- Add a contributor only when a GitHub account, Git authorship, and accessible
  Beacon-specific commit or pull request can be verified.
- Preserve official upstream commits and authors during synchronization; an
  inherited upstream author is not automatically a Beacon-specific contributor.
- Correct aliases or attribution through a pull request with traceable evidence.

The complete commit history remains authoritative for code provenance.
